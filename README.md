# portfolio-website
Overview

This project is a responsive personal portfolio website built using HTML, CSS, and JavaScript and deployed on Amazon Web Services (AWS). The website highlights personal skills, projects, and contact information while demonstrating practical knowledge of cloud-based static website hosting.

The application is hosted on Amazon S3 and distributed globally using Amazon CloudFront, ensuring fast load times and secure HTTPS access.

Technologies & Services

Frontend: HTML5, CSS3, JavaScript

Cloud Hosting: Amazon S3 (Static Website Hosting)

Content Delivery: Amazon CloudFront (CDN)

Security: HTTPS enforcement, AWS Shield Standard

Access Control: IAM & S3 bucket policies

Deployment Summary

Static website files are hosted in an Amazon S3 bucket

Public access is configured securely using bucket policies

CloudFront is used as a CDN to deliver content globally

HTTP requests are automatically redirected to HTTPS

Basic security protections are enabled using AWS-managed services
